
# Stock Portfolio Tracker

## About
A beginner-friendly Python project that calculates
the total investment in a stock portfolio.

## Features
- Enter stock names
- Add share quantities and prices
- Calculate individual investments
- Display total investment
- Save portfolio details to a text file

## Technologies Used
- Python
- Random? No external libraries required

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Run the command:

   python StockPortfolioTracker.py

## Output
Displays individual stock investments and the total
portfolio investment, then saves the details to portfolio.txt.
